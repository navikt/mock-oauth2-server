Click-through helper for the authorize-params feature. It is served by the mock server itself under /static/, so redirect_uri can simply point back at this page: fill in the fields, press Authorize & log in — the page redirects to /<issuer>/authorize, then automatically exchanges the returned code at /<issuer>/token. Works in non-interactive mode directly, and with interactiveLogin: true via the server login form in between. Exchange config round-trips inside state.
